# Main Character Barbearia

Site de uma barbearia fictícia desenvolvido com HTML, CSS e JavaScript.

## Sobre o projeto

A Main Character é uma barbearia com identidade visual moderna, masculina e minimalista, utilizando tons de preto, roxo, vermelho e amarelo.

## Funcionalidades

- Tela de login com validação
- Página inicial da barbearia
- Apresentação dos serviços
- Seção de benefícios e informações da empresa
- Navegação entre páginas
- Layout responsivo
- Logout

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.

Projeto acadêmico desenvolvido para praticar HTML, CSS, JavaScript, estilização de páginas e integração entre uma tela de login e um site.
