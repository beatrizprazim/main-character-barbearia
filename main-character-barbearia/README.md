# Main Character Barbearia

Site fictício de barbearia criado com HTML, CSS e JavaScript para atividade acadêmica. Inclui login demonstrativo conectado à página principal, navegação responsiva, seções sobre a barbearia, serviços, benefícios, formulário de agendamento simulado e logout.

## Como executar

1. Abra a pasta `main-character-barbearia` no VS Code.
2. Abra o arquivo `index.html` no navegador, ou use a extensão Live Server.
3. Entre com **usuário:** `cliente` e **senha:** `123456`.
4. Você será direcionado a `home.html`.

## Funcionalidades

- Validação dos campos e das credenciais demonstrativas
- Mostrar/ocultar senha
- Redirecionamento após login e bloqueio demonstrativo de acesso à página sem sessão
- Logout e menu responsivo
- Navegação por âncoras
- Formulário demonstrativo de agendamento, sem envio de dados ou reserva real

## Tecnologias

HTML5, CSS3, JavaScript puro, Google Fonts e fotografias externas do Unsplash.

## Aviso

Este projeto **não possui backend nem autenticação segura**. As credenciais estão visíveis no JavaScript e a sessão é armazenada no `sessionStorage`. Não use dados reais ou senhas pessoais. O agendamento é apenas uma simulação acadêmica. A exibição das fontes e fotografias depende de internet.
